Slack通知に対応

日次サマリーをSlackに自動投稿。チームでの共有もスムーズに。

導入は5分。

必要なのはMac、Python、そしてNotionアカウントだけ。

1

クローン

git clone して pip install。それだけ。

2

APIキーを設定

Gemini と Notion のキーを .env に記入。

3

DBを自動作成

setup_notion.py がNotion DBを自動生成。

4

常駐化

setup_launchd.sh install で完了。
